Programación visual · Arduino

Programación visual para Arduino

ArduBlock genera código C++ a partir de bloques, compila y sube el programa a la placa desde el navegador. Incluye crear aulas con estudiantes para monitorear su trabajo. Los proyectos se guardan local en el navegador o con cuenta.

Abrir editor

Funcionalidades

Editor por bloques

Interfaz Blockly: entrada/salida digital y analógica, servo, LCD, sensores, variables y estructuras de control.

Código C++ en vivo

Cada bloque genera su equivalente en C++ al instante, con pestañas .ino y .h editables.

Compilar y subir

Un botón detecta la placa, compila con arduino-cli y sube por USB. Instala automáticamente los cores que falten.

Monitor serial

Consola integrada con selector de baud rate para leer y enviar datos a la placa.

Aulas con código de acceso

El profesor crea un aula y obtiene un código de 6 caracteres. Los estudiantes se unen con ese código.

Dashboard del profesor

Ver la lista de estudiantes de cada aula y revisar sus proyectos y el código generado.

Modo invitado

El editor funciona sin cuenta; los proyectos se guardan en el navegador.

Validación pedagógica

Avisos sobre los bloques antes de compilar: errores como pines sin configurar o bloques sueltos.

Cómo funciona

El profesor crea un aula

Desde el dashboard obtiene un código de acceso de 6 caracteres.

Los estudiantes se unen y programan

Se registran con el código del aula y arman el programa arrastrando bloques.

Suben a la placa y el profesor revisa

Conectan el Arduino, suben el sketch y el profesor revisa el avance desde su panel.

Roles

Profesor

  • Crea aulas y obtiene códigos de acceso
  • Revisa proyectos y código C++ de cada estudiante
  • Para probar la plataforma, escribí a javier@matemancia.net

Estudiante

  • Se registra con el código de clase que le da su profesor
  • Programa con bloques y sube a la placa
  • Guarda sus proyectos con su cuenta

Invitado

  • Usa el editor sin cuenta
  • Los proyectos quedan guardados en el navegador
